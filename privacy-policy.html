Política de Privacidade - PlantOn

O PlantOn é um aplicativo para organização pessoal de plantões. O aplicativo não exige cadastro, login ou criação de conta.

Dados armazenados pelo aplicativo

Os dados inseridos pelo usuário, como plantões, locais de trabalho, férias, faltas, trocas, extras e configurações, são armazenados localmente no dispositivo do usuário.

Backup dos dados

O aplicativo permite que o usuário gere um arquivo de backup em formato JSON. Esse arquivo é criado somente mediante ação do usuário e pode ser salvo ou compartilhado pelo próprio usuário conforme sua escolha.

Compartilhamento de dados

O PlantOn não possui servidor próprio e não envia os dados de plantões do usuário para uma base externa controlada pelo desenvolvedor.

Anúncios

O aplicativo utiliza o Google AdMob para exibição de anúncios. O Google AdMob pode coletar dados técnicos, identificadores do dispositivo e informações relacionadas a anúncios, conforme as políticas do Google.

Exclusão dos dados

O usuário pode apagar os dados do aplicativo a qualquer momento limpando os dados do app nas configurações do dispositivo ou desinstalando o aplicativo.
