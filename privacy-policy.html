Política de Privacidade

Esta Política de Privacidade explica como o aplicativo PlantOn trata as informações utilizadas para organizar plantões, locais, férias, faltas, trocas e extras.

Última atualização: 17 de abril de 2026.

O PlantOn não exige cadastro, login ou criação de conta. Os dados de plantões cadastrados pelo usuário ficam armazenados localmente no próprio dispositivo.

1. Quem somos

O PlantOn é um aplicativo de organização pessoal de plantões, desenvolvido para ajudar o usuário a visualizar escalas, registrar faltas, trocas, férias, plantões extras e acompanhar informações de trabalho.

2. Dados informados pelo usuário

O usuário pode inserir informações como:

  • datas, horários e tipos de plantão;
  • locais de trabalho cadastrados pelo usuário;
  • férias, faltas, trocas e plantões extras;
  • observações adicionadas manualmente;
  • estado e município escolhidos para exibição de feriados locais;
  • valores monetários relacionados a plantões extras, quando cadastrados pelo usuário.

Essas informações são usadas para o funcionamento do próprio aplicativo e para exibir calendários, análises e resumos ao usuário.

3. Armazenamento local

Os dados de organização de plantões são armazenados localmente no dispositivo do usuário. O PlantOn não possui servidor próprio para receber, processar ou armazenar esses dados.

Caso o usuário desinstale o aplicativo, limpe os dados do app ou troque de dispositivo sem realizar backup, as informações locais podem ser perdidas.

4. Backup e restauração

O PlantOn permite que o usuário gere um arquivo de backup em formato JSON. Esse arquivo é criado somente mediante ação do usuário.

O usuário decide onde salvar, compartilhar ou armazenar esse arquivo. Ao restaurar um backup, os dados presentes no arquivo são importados novamente para o aplicativo.

5. Anúncios e serviços de terceiros

O aplicativo utiliza o Google AdMob para exibição de anúncios. Serviços de anúncios podem coletar ou processar dados técnicos, identificadores do dispositivo, informações de interação com anúncios e dados necessários para medição, segurança, prevenção de fraude e personalização, conforme as políticas do Google.

Para saber mais, consulte a política de privacidade do Google: https://policies.google.com/privacy.

6. Compartilhamento de dados

O PlantOn não vende os dados informados pelo usuário e não compartilha os dados de plantões com servidores próprios do desenvolvedor.

O compartilhamento pode ocorrer apenas quando o próprio usuário exporta, salva, envia ou restaura um arquivo de backup, ou quando serviços de terceiros, como o Google AdMob, realizam tratamentos de dados conforme suas próprias políticas.

7. Permissões do dispositivo

O aplicativo pode utilizar permissões necessárias para funcionalidades como anúncios, acesso a arquivos de backup ou recursos exigidos pelo sistema operacional. As permissões solicitadas podem variar conforme a versão do Android e as funcionalidades utilizadas pelo usuário.

8. Segurança

O PlantOn busca manter os dados do usuário no próprio dispositivo. Ainda assim, o usuário é responsável por proteger o acesso ao aparelho, manter backups em locais seguros e evitar compartilhar arquivos de backup com pessoas não autorizadas.

9. Exclusão dos dados

O usuário pode excluir os dados do PlantOn limpando os dados do aplicativo nas configurações do dispositivo ou desinstalando o app. Arquivos de backup salvos fora do aplicativo devem ser excluídos manualmente pelo próprio usuário no local onde foram armazenados.

10. Privacidade de crianças

O PlantOn não é direcionado a crianças. O aplicativo foi criado para uso pessoal por profissionais que desejam organizar plantões e rotinas de trabalho.

11. Alterações nesta política

Esta Política de Privacidade pode ser atualizada para refletir melhorias no aplicativo, mudanças legais ou ajustes em serviços utilizados. A data de atualização será revisada sempre que houver alterações relevantes.

12. Contato

Em caso de dúvidas sobre esta Política de Privacidade ou sobre o tratamento de dados no PlantOn, entre em contato pelo e-mail: suporte@dmbsoftware.com.br.
